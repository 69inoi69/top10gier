# TOP 10 GIER — Hall of Fame 🏆

A university project for the **Web Technologies** course (Technologie Webowe).

👉 **[69inoi69.github.io/top10gier](https://69inoi69.github.io/top10gier/)**

My personal ranking of the ten best games ever. The code was largely written by AI, but the list and the reviews are 100% my own opinion, and I'll defend it to the end.

The site itself is in Polish, since it was made for a Polish university course.

> Rzeczywistość ma kiepską fabułę, straszny grind i jest pay-to-win.
> Dlatego wybrałem inną drogę.
>
> *(Reality has a bad plot, a terrible grind, and it's pay-to-win. So I chose another way.)*

## The ranking

| Tier | Games |
| --- | --- |
| **Emerald** 🟢 | F.E.A.R., Dark Souls: Remastered |
| **Diamond** 💎 | SOMA, Neon White, Hades, Metro Exodus |
| **Gold** 🟡 | Silent Hill 2, Darkwood, Fallout: New Vegas, Half-Life |

Click a game card to open a preview with a review (a bit less serious than it should be), pros, cons, a verdict and a Steam link. Each preview takes on the color of its tier.

## What's on the page

- ⌨️ A typewriter intro
- 📚 The library "loads" on the first screen: covers of all 10 games light up one by one in their tier colors — click any to open its preview
- 🃏 Game cards that open a preview (close it with ×, a click outside, or `Esc`)
- 📧 A newsletter form that says thanks but never sends anything — there's no backend, it's a course project
- ⬆️ A back-to-top button and a header that hides while you scroll
- 🎨 A hand-made logo in `grafika/samodzielna_grafika/`
- 🐈 Schrödinger's cat in the bottom-left corner — try to catch it

## Tech

No frameworks, no build step, no `node_modules` — just HTML, CSS and JavaScript.

```
index.html   — the whole page (one-page site)
style.css    — styles
script.js    — game data (the GAMES object) and all the logic
grafika/
  glowna/               — avatar and tier icons
  karteczki/            — images on the game cards
  gry/                  — artwork shown in the game preview
  samodzielna_grafika/  — logo
```

To run it, just open `index.html` in a browser. The live version is on GitHub Pages.
